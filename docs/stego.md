# Stego & Mutation Lab

> Transforms, steganography, PromptCraft, tokenizer — purple-team utilities.

[Open in app](http://localhost:3333/docs/stego)

Inspired by P4RS3LT0NGV3. Use for authorized purple-team channel testing and prompt mutation — not for hiding real exfil from production defenses without mandate.

- Transforms — base64, ciphers, Unicode styles, leetspeak, prompt wraps
- Emoji / invisible (zero-width) steganography
- Mutation Lab — batch variants
- PromptCraft — local heuristic mutation (LLM optional)
- Universal decoder + tokenizer visualization
- Tokenade — feather-capped stress payloads (lab only)
