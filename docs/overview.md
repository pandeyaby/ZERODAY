# Overview

ZERODAY turns an existing AI coding agent into a **structured, auditable security operator**. Its results export to the formats security teams already use (SARIF for GitHub Code Scanning, plus AWS Security Hub, Splunk CIM, Cortex XSOAR, FortiSIEM and CrowdStrike files). It is an independent open-source project, not affiliated with or endorsed by any of those vendors.

Hard properties: keyless by default, self-hosted, offline-capable, durable evidence.

Defensive localization only — not red-team theater.
