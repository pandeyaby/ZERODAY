# First-time users

1. `npm install`
2. `npm run mvp`  → expect **PASS** and SARIF paths under `zeroday-reports/mvp/`
3. Optional Operator UI: `npm run play` → http://localhost:3333/play
4. Live Antares (opt-in, costs $): `npm run zeroday -- antares doctor` (print-only)

You do not need a GPU or Hugging Face token for the MVP / fixture path.
