# Real-shaped Desk sample (Keyless K5)

Tiny tree that mirrors a normal app layout so CI can exercise:

```bash
npm run zeroday -- inventory --repo fixtures/inventory/real-shaped
```

Same shape as running `inventory` with cwd default on a real project.
Fixtures remain available via `inventory --fixture` / `npm run mvp`.
Not localization / vuln discovery — Desk config inventory only.
