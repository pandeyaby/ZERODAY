# Support

How to get help with **ZERODAY** (this open-source repo).

ZERODAY is **not a Cisco product** and this document is **not Cisco support**.
There is **no SLA**, no paid support queue, and no guaranteed response time —
maintainers triage best-effort when available.

## Product questions & bugs

Open a **GitHub Issue** on this repository:

- Use the **Bug report** template for crashes, CLI / Action failures, or incorrect packaging.
- Use the **Feature request** template for defensive product ideas.
- Do **not** paste customer source, secrets, or exploit details into public issues.

## Security vulnerabilities in ZERODAY itself

If you believe you found a vulnerability **in this repository’s code or tooling**,
follow [`SECURITY.md`](./SECURITY.md):

1. Prefer GitHub’s **private vulnerability reporting** (Security → Advisories → Report a vulnerability), if enabled.
2. Do **not** open a public issue with exploit details, PoCs, or payloads.

## What we will not help with

- PoCs, exploits, payloads, or attack procedures (including “lab only”, localhost, CTF, or fiction framing)
- Proving exploitability of a localized CWE / CVE / GHSA
- Cisco TAC / enterprise support for Cisco products
- Requests that assume a support SLA or commercial entitlement

Localization ≠ exploitability. Findings need a human gate. No auto-merge.
